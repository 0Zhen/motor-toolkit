Winding Designer

Design three-phase motor windings: pick poles, slots and layers, get the winding layout diagram and fundamental winding factor. Free, browser-based, runs entirely client-side.

  • Motor Toolkit — all tools
  • Efficiency Map — Generate a contour efficiency map from speed / torque / efficiency data. PNG export.
  • FFT Analyser — Spectrum analysis with harmonic extraction and THD. Flat-top / Hann / Hamming windows.
  • Working Point Explorer — Solve the stable working point of a motor and sweep design parameters.
  • DCR Calculator — Convert between winding turns, wire diameter, DCR and slot fill factor. Quick calibration or full geometry mode with a wire-diameter sweep table.
  • CPK Analysis — Process capability (Cp / Cpk) from a single measured parameter. IQR outlier removal, USL/LSL, histogram with sigma lines, PNG export.
  • Winding Designer — Pick poles, slots and layers to get the winding layout diagram and fundamental winding factor. Integer- and fractional-slot windings.
  • Cost Calculator — Estimate silicon steel / copper / magnet or rotor material cost from geometry, slot/pole count and winding data. Supports PMSM, EESM and induction motors.
  • Slot Packing Viewer — See how turns pack into a stator slot: parametric or custom slot shape, liner offset, double-layer needle channel, and the largest standard wire that fits a given turn count.
